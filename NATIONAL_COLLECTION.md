# Nationwide official collection

`scripts/collect-national.mjs` is generated from the Muryoum backend source. Its header records the SHA-256 of the normalization, venue matching and collection sources, with line endings normalized before hashing. From the application repository's `backend` directory, run `node scripts/bundle-national.mjs`, then copy `backend/dist/collect-national.mjs` here and to `ops-template/scripts`. Do not edit the generated bundle manually.

The workflow reads all pages of the official public datasets 15013110 and 15013109, validates completeness and current course dates, stages batches in the Muryoum API, and publishes only after the complete count is confirmed. National dates are not claims of live registration availability and do not create time-specific alarms. Only exact education-address and institution matches receive library coordinates. No location is inferred from a regional center.

As of 2026-11-05, national metadata is checked every day at 10:43 KST. Modification date, row count and columns are compared; changes trigger a full download. Monday performs full reconciliation even when metadata is unchanged, covering same-row-count content edits. Library metadata is checked Monday at 10:13 KST; the first Monday of each month performs full reconciliation. Validated minimal library fields are reused between downloads. Expired course dates are still filtered when users search. The workflow runs only when `NATIONAL_COLLECTION_ENABLED=true`. The existing repository secret `MURYOUM_ADMIN_TOKEN` is sent only to the fixed Muryoum origin with redirects disabled. No public data API key is required for these official downloadable datasets.

Confirmation timestamps and time-derived statuses are excluded from content fingerprints. An identical full source skips course rows and detail-chunk rewrites, updating only confirmation metadata. Current and previous published detail versions have no automatic TTL; daily cleanup removes only unreferenced older versions. Invalid or incomplete sources preserve the last verified publication. At the account budget threshold or with stale telemetry, optional full collection waits for fresh acceptable telemetry.

After publication the backend writes an atomic read snapshot to the free Muryoum KV namespace. Public search and saved-course updates do not read D1. D1 collection still has its free limits; a failed collection preserves the last verified public snapshot. Seoul retention cleanup now receives a started_at index before collection, preventing repeated scans of seven days of run history. User instruction: keep the free plan; do not upgrade billing.

Verification on 2026-11-05: official snapshot 29,637 rows; 6,455 validated courses. Identical full reconciliation wrote zero course rows, two D1 metadata rows and no detail chunks (run 41985190959). The metadata-only check wrote one D1 row and zero KV values (run 41991455186). These are individual execution measurements, not whole-account or billing savings. Backend tests: 59 PASS; Seoul orchestration tests after concurrency/diagnostic hardening: 37 PASS.
